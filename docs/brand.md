# Brand

How ZarrExtract looks, and how to use its name, mark and colours.

## Name

- **ZarrExtract** in prose, headings and titles.
- `zarrextract` in code type for the package: `pip install zarrextract`,
  `import zarrextract as zx`.

## Mark

A 3 × 3 grid of square chunks. Seven blue chunks, joined by thin links,
form a **Z**: the top row, the diagonal through the centre, and the bottom
row. The middle-left cell is empty. In the middle-right cell, a small
jade **X**, made of four squares, sits half its width outside the grid, as
if being extracted: ZarrExtract reads only the chunks it needs.

| File | Use |
| --- | --- |
| `_static/brand/zarrextract-mark.svg` | The mark on light backgrounds |
| `_static/brand/zarrextract-mark-dark.svg` | The mark on dark backgrounds |
| `_static/brand/zarrextract-lockup.svg` | Mark and name on light backgrounds |
| `_static/brand/zarrextract-lockup-dark.svg` | Mark and name on dark backgrounds |
| `_static/brand/favicon.svg`, `favicon.ico` | Browser tabs (16, 32, 48 px) |
| `_static/brand/zarrextract-mark-512.png` | Where an image file is needed |

At favicon sizes the X becomes one solid jade square, because its four
small squares merge at 16 px.

Keep the mark's proportions, corners and colours. Don't round the corners,
recolour the links, or add effects such as shadows or gradients.

## Colours

| Role | Light mode | Dark mode |
| --- | --- | --- |
| Blue: the grid, "Zarr", links | `#0B5D7A` | `#5FC1D9` |
| Jade: the X, "Extract" | `#13805A` | `#4CBF8C` |
| Dark background | | `#0F1A20` |

Both colours meet WCAG contrast for text: jade `#13805A` is 4.9:1 on
white, and `#4CBF8C` is 7.7:1 on `#0F1A20`.

## Type

- **Wordmark:** Oxanium Medium (500) for both words, outlined in the SVG
  files, so the font isn't needed to show them. "Zarr" in blue,
  "Extract" in jade.
- **Documentation:** the theme's system fonts, for readability; Oxanium is
  only used in the wordmark.
